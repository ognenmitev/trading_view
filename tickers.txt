# TradingView Multi-Window Launcher - Tickers Configuration
# ===========================================================
#
# HOW TO USE:
# -----------
# • Add one ticker per line
# • Lines starting with # are comments (ignored)
# • Remove # to activate a ticker
# • The script will open one window per ticker
#
# SUPPORTED LAYOUTS:
# ------------------
# • 1 ticker  → Full screen
# • 2 tickers → Side by side (50/50)
# • 3 tickers → 2 on top, 1 on bottom left (quarters)
# • 4 tickers → 2×2 grid (quarters)
# • 5-6 tickers → First 4 in 2×2 grid, remaining maximized
# • 7+ tickers → First 4 in 2×2 grid, remaining maximized
#
# 💡 For 5+ windows: First 4 auto-arrange, then manually position
#    the rest using Rectangle shortcuts (Ctrl+Opt+U/I/J/K)
#
# TICKER FORMATS:
# ---------------
# • Stock: AAPL, TSLA, MSFT
# • ETF: SPY, QQQ, IWM
# • Forex: EURUSD, GBPUSD
# • Crypto: BTCUSD, ETHUSD
# • Futures: ES1!, NQ1!, GC1!, CL1!
# • With exchange: NASDAQ:AAPL, NYSE:BA, CME_MINI:ES1!
#
# ===========================================================
